# JoyPlanner 🎈

## About The App
**JoyPlanner** is a full-stack event and task management web application designed to simplify party and event planning. Users can browse event tiers (**Bronze**, **Silver**, and **Gold**), create and customize their own events, track schedules, and attach managed task lists directly to each event. 

### Background
Planning events often becomes overwhelming when managing logistics across multiple notes or applications. JoyPlanner was built to provide a centralized dashboard where planners can create events, monitor dates and times, and break down complex event preparations into actionable tasks with real-time updates.

## Technologies Used

* **Front-End:** React (v18+), React Router DOM (v6/v7), Vite
* **Languages:** JavaScript (ES6+), HTML5, CSS3
* **State & Navigation:** React Hooks (`useState`, `useEffect`, `useParams`, `useNavigate`)
* **HTTP Client:** Fetch API / Axios
* **Authentication:** JWT (JSON Web Tokens) with Local Storage persistence
